Place the official PAD-UFES-20 images under `data/images/` and metadata as `data/metadata.csv`.
Required columns: `img_id` (filename), `patient_id` (patient identifier), `diagnostic` (ACK/BCC/MEL/NEV/SCC/SEK).
If your extracted archive's paths or metadata column names differ, adapt the CSV before running prepare.py. Dataset files are NOT redistributed in this repository.
